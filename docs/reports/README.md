# Test run reports

Store filled reports here as `YYYY-MM-DD-<trigger>-<short-sha>.md`, or paste the same structure into Notion.

- Template: [`../templates/test-run-report.md`](../templates/test-run-report.md)
- Filled example: [`../templates/test-run-report.example.md`](../templates/test-run-report.example.md)

Do not commit secrets, `.env` contents, or raw credential values in reports.
