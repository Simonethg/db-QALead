# DEF-001: Demoblaze login modal has WCAG 2.1 AA violations

## Severity

High (blocks ADA compliance for authenticated flows)

## Priority

Medium

## Environment

- URL: https://www.demoblaze.com
- Browser: Chromium 151 (Desktop Chrome)
- Tool: `@axe-core/playwright` with rules `wcag2a`, `wcag2aa`, `wcag21aa`
- Test: `tests/ui/accessibility.spec.ts`

## Steps to reproduce

1. Open https://www.demoblaze.com.
2. Click **Log in** in the navigation bar.
3. Run an axe-core scan on the page while the login modal is visible.

## Expected result

No critical or serious WCAG 2.1 AA violations are detected on the login modal.

## Actual result

 axe-core detects multiple critical and serious violations:

1. **color-contrast (serious)**
   - Elements: `#logInModalLabel`, `label[for="log-name"]`, `label[for="log-pass"]`
   - Foreground: `#868688`, background: `#ffffff`
   - Contrast ratio: 3.63:1 (required 4.5:1 for normal text)

2. **image-alt (critical)**
   - Elements: two `<img>` tags in the navbar without `alt` attributes.
   - Example: `<img width="50" height="50" src="blazemeter-favicon-512x512.png">`

3. **label (critical)**
   - Elements: `#loginusername`, `#loginpassword`
   - The visible labels use `for="log-name"` and `for="log-pass"`, but the inputs have `id="loginusername"` and `id="loginpassword"`. The `for` and `id` values do not match, so screen readers cannot associate labels with inputs.

## Evidence

- Playwright trace: `test-results/ui-accessibility-*-chromium/trace.zip`
- Screenshot: `test-results/ui-accessibility-*-chromium/test-failed-1.png`
- Axe report: generated by `npm run test` in `playwright-report/`

## Impact

- **ADA / WCAG:** Users relying on screen readers or with low vision cannot reliably use the login flow.
- **SOC 2 Type II:** Accessibility defects in customer-facing authentication are audit findings if not tracked and remediated.
- **Risk:** Login is the entry point for all authenticated flows; an inaccessible login blocks access for users with disabilities.

## Recommended action

1. Match label `for` attributes to input `id` attributes on the login modal.
2. Add descriptive `alt` text to all images, or use `role="presentation"` for decorative images.
3. Increase color contrast for modal labels and titles to at least 4.5:1.
4. Add an automated accessibility gate to CI so regressions are caught before release.

## Status

Open — reported during QA Automation Lead technical challenge, tracked as evidence for ADA compliance review.
